# Roadmap

## v0.1.0 — Foundation

- Package, CLI, manifest schema, setup CRUD, tests, and CI.

## v0.2.0 — Capture Preview

- Process, port, Git, editor, and Docker inspection.
- Dry-run setup generation.

## v0.3.0 — Command Launching

- Dependency graph, subprocess supervision, readiness checks, and stop behavior.

## v0.4.0 — Developer Integrations

- Docker Compose, VS Code, Cursor, terminal, and project-local setups.

## v0.5.0 — macOS Workspace Capture

- Applications, browser integration, window geometry, and permissions flow.

## v0.6.0 — Trust and Security

- Audit, trust hashes, secret references, redaction, and plugin isolation.

## v0.7.0 — Runtime Management

- Status, logs, reconciliation, port conflicts, and idempotent relaunching.

## v0.8.0 — Plugin Preview

- External executable protocol and sample plugin.

## v0.9.0 — Release Candidate

- Full tests, documentation, performance review, migration tests, and packaging.

## v1.0.0 — Stable macOS Release

- Documented supported adapters.
- Stable manifest schema version 1.
- Stable plugin protocol version 1.
- PyPI and Homebrew installation.
- Production-grade safety and diagnostics.

## Post-1.0

### v1.1

- Better terminal integrations.
- Setup templates.
- Shell completion improvements.

### v1.2

- Linux technical preview.

### v1.3

- Team-shared manifests and environment checks.

### v2.0 candidates
